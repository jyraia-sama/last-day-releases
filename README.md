# Last Day — versions publiées

Ce dépôt contient uniquement les versions publiées du jeu **Last Day** (pas le code source).

- `latest.json` : numéro de la dernière version et lien vers son fichier de contenu.
- `builds/LastDay-x.y.z.pck` : contenu du jeu pour chaque version.

Au lancement, `LastDay.exe` lit `latest.json` et télécharge seul la nouvelle version si besoin.
